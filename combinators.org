* Notes on Dyalog APL
Use /tacks/ (~⊣~, ~⊢~) and /atop/ (~⍤~) to specialize forks.
- e.g. ~(⊣ g h)~ or ~(f g h⍤⊢)~ (only right arg. goes into ~h~)

Ambiguous function compositions in forks can often be resolved with either
parens or preprocessing operators like /beside/ ~∘~, e.g.:
:       (⌽,-⌊/)
: ┌─┴─┐
: ⌽ ┌─┼─┐
:   , - /
:     ┌─┘
:     ⌊
:       (⌽,(-⌊/))
: ┌─┼──┐
: ⌽ , ┌┴┐
:     - /
:     ┌─┘
:     ⌊
:       (⌽,∘-⌊/)
: ┌─┼────┐
: ⌽ ∘    /
:  ┌┴┐ ┌─┘
:  , - ⌊
